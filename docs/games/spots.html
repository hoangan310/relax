Nho vi tri

Nhin cac o sang len trong choc lat. Sau do hay cham lai dung cac vi tri con vua thay.

Dieu khien

Bam "Bat dau" de xem cac vi tri duoc to sang.
So o can nho: 3
  1. Nhin cac o sang len.
  2. Khi bang tro lai binh thuong, cham lai cac o do.
  3. Moi lan dung, so o can nho se nhieu hon mot chut.
